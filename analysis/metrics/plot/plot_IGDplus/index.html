    plot IGD+

    purpose

    The plot_IGDplus method calculates the IGD+ of objectives across generations and plots the results.

    configuration

    variables types

    The method accepts variables of type experiment.result . For a better understanding of this variable, access the link:

    variable experiment.result

    supported variables

    Any number of variables are accepted:

    1
    moeabench.plot_IGDplus(exp1.result, exp2.result, exp3.result..)

    flexibility

    The user can assign the following settings

    generation range

    Any generation interval can be chosen. The graph will be plotted according to that range:

    Note: the metric calculation is performed for all objectives within the given range.

    1
    moeabench.plot_IGDplus(exp3.result, exp2.result, exp.result,  generations = [50,200])
    ![alt text](img_IGDplus/IGDplus_1.jpeg) #### combination objectives

    IGD+ calculations can be performed with any combination of objectives.

    Note: The metric calculation is based on the objectives selected for all generations.

    1
    moeabench.plot_IGDplus(exp3.result, exp2.result, exp.result,  objectives = [2,3])

    generation range and combination objectives

    It is possible to plot with a generation range and a given combination of objectives.

    1
    moeabench.plot_IGDplus(exp3.result, exp2.result, exp.result,  generations = [90,240],  objectives = [1,2])

    default

    In default mode, IGD+ is calculated with all objectives and all generations.

    1
    moeabench.plot_IGDplus(exp3.result, exp2.result, exp.result)

    exceptions

    To protect the integrity of the data passed as parameters, certain rules and exceptions are considered.Information regarding exceptions and rules can be accessed at this link:

    exceptions and rules
