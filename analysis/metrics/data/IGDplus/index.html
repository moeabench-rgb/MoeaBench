    IGD+

    purpose

    The IGDplus method calculates the IGD+ of objectives across generations.

    configuration

    variables types

    The method accepts variables of type experiment.result . For a better understanding of this variable, access the link:

    variable experiment.result

    data format

    An array is returned from the method, which can be stored in a variable and manipulated in any way the user prefers:

    1
    IGD = exp.IGD()

    flexibility

    The user can assign the following settings

    generation range

    Any generation interval can be chosen. The returned array will be in accordance with this range.

    Note: the metric calculation is performed for all objectives within the given range.

    1
    IGDplus_gen_130_150 = exp.IGDplus(generations = [130,150])

    Note: The metric calculation is based on the objectives selected for all generations.
