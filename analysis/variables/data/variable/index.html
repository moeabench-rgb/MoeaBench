    Variables in generations

    purpose

    The variable The variable method uses decision variables in an evolutionary algorithm across generations. The method requires, as a parameter, a specific variable for the benchmark problem to return the data.

    configuration

    data format

    An array is returned from the method, which can be stored in a variable and manipulated in any way the user prefers:

    1
    objective = exp.objective()

    flexibility

    The user can assign the following settings

    generation range

    Any generation interval can be chosen. The returned array will be in accordance with this range.

    Note: The example below shows the decision variables of the evolutionary algorithm for objective one, throughout generations 130 and 131.

    1
    variable_var_5_gen_130_132 = exp.variable(variable = 1, generations = [130,132])

    The array contains two inner arrays, corresponding to the two generations within this interval.

    Accessing the array related to the variable objective_130_132 at position zero, corresponding to generation 130.

    1
    variable_var_5_gen_130_132[0]
