    DTLZ1

    The DTLZ1 problem has a Pareto optimal front formed by a linear hyperplane:

    \[ \boldsymbol{\textcolor{blue}{f_1}(X)} + \underbrace{\boldsymbol{\textcolor{blue}{f_2}(X)} + \boldsymbol{....}}_{\text{M > 3} } + \boldsymbol{\textcolor{blue}{f_{M-1}}(X)} + \boldsymbol{\textcolor{blue}{f_{M}}(X) = 0.5} \Longrightarrow \boldsymbol{\sum_{m=1}^M\textcolor{blue}{f_{M}^*} = 0.5} \]

    DTLZ1 is defined by the following variables:

    • M: Number of objectives of the problem
    • N: Number of decision variables
    • K: represented by:
    \[ \boldsymbol{K}\text{ is the value of the vector } \boldsymbol{\big|X_M\big|} \text{ where all } \boldsymbol{X_i} \text{ belong to } \boldsymbol{X_M}\text{ }\boldsymbol{(X_i \in X_M)} \]

    The value of N can be obtained from the equation N = K+M-1 by substituting the value of K. Alternatively, the value of K can be defined by the equation K = N-M+1, substituting the value of N.

    Example

    For M = 3

    \[ \large \underbrace{f_1}_{\boldsymbol{\textcolor{blue}{f_1}(X)}}, \underbrace{f_2}_{\boldsymbol{\textcolor{blue}{f_{M-1}}(X)}}, \underbrace{f_3}_{\boldsymbol{\textcolor{blue}{f_M}(X)}} \]

    Where f1 ,f2 and f3 are the objective functions according to the total number of (M = 3).

    Define the value of K assuming N = 10, using the equation:

    K = 10-3+1 = 8.

    Or

    Define the value of N assuming K = 8, using the equation:

    N = 8+3-1 = 10.

    For the problem with M = 3, N = 10 and K = 8, we have:

    \[ \large x_1, \underbrace{x_2}_{\boldsymbol{X_{M-1}}}, \underbrace{\underbrace{\underbrace{x_3}_{\boldsymbol{X_M}}, x_4, x_5, x_6, x_7, x_8, x_9, x_{10}}_{\boldsymbol{K = \big|X_M\big| = (X_I \in X_M)}}}_{\textcolor{darkred}{\Large \boldsymbol{g(X_M)}}} \]

    The positions XM-1 and XM are represented by x2 and x3, respectively. The vector size | XM | is defined by K = 8, starting at x3 and continuing until the last K = 8 variables, denoted by x10.

    The function g( XM ) corresponds to the decision variables within the range of | XM | (x3 x4 x5 x6 x7 x8 x9 x10), and must be minimized by evolutionary algorithms (MOEAs). When this function reaches g = 0, the Pareto optimal front of the problem is found.

    For M = 4

    \[ \large \underbrace{f_1}_{\boldsymbol{\textcolor{blue}{f_1}(X)}}, \underbrace{f_2}_{\boldsymbol{\textcolor{blue}{f_2}(X)}}, \underbrace{f_3}_{\boldsymbol{\textcolor{blue}{f_{M-1}}(X)}}, \underbrace{f_4}_{\boldsymbol{\textcolor{blue}{f_M}(X)}} \]

    Where f1, f2, f3, and f4 are the objective functions according to the total number of (M = 4).

    Define the value of K assuming N = 10, using the equation:

    K = 10-4+1 = 7.

    Or

    Define the value of N assuming K = 7, using the equation:

    N = 7+4-1 = 10.

    For the problem with M = 4, N = 10 and K = 7, we have:

    \[ \large x_1, x_2, \underbrace{x_3}_{\boldsymbol{X_{M-1}}}, \underbrace{\underbrace{\underbrace{x_4}_{\boldsymbol{X_M}}, x_5, x_6, x_7, x_8, x_9, x_{10}}_{\boldsymbol{K = \big|X_M\big| = (X_I \in X_M)}}}_{\textcolor{darkred}{\Large \boldsymbol{g(X_M)}}} \]

    The positions XM-1 and XM are represented by x3 and x4, respectively. The vector size | XM | is defined by K = 7, starting at x4 and continuing until the last K = 7 variables, denoted by x10.

    The function g( XM ) corresponds to the decision variables within the range of | XM | (x4 x5 x6 x7 x8 x9 x10), and must be minimized by evolutionary algorithms (MOEAs). When this function reaches g = 0, the Pareto optimal front of the problem is found.

    Function g

    The purpose of the function g( XM ) is to maximize the distance from the POF of the problem, attracting the evolutionary algorithms to local Pareto fronts.

    When the vector | XM | reaches the values | 0.5 0.5 .... 0.5 |, the true POF of the problem is obtained.

    \[ \textcolor{darkred}{\boldsymbol{g(X_M)} = 100 \bigg[\big|X_m\big|+\displaystyle\sum_{X_I \in X_M} (x_i-0.5)^2-\cos(20\pi(x_i-0.5))\bigg]} \]

    Objective functions

    Each objective function receives a value from the function g( XM ). The POF of the problem is directly linked to g( XM ).

    \[ \textcolor{blue}{f_1}(X)=\frac{1}{2}x_1 x_2...x_{M-1}(1+\boldsymbol{\textcolor{darkred}{g(X_M)}}), \]
    \[ \textcolor{blue}{f_2}(X)=\frac{1}{2}x_1 x_2...(1-x_{m-1})(1+\boldsymbol{\textcolor{darkred}{g(X_M)}}), \]
    \[ \textcolor{blue}{f_{M-1}}(X)=\frac{1}{2}x_1 (1-x_2)(1+\boldsymbol{\textcolor{darkred}{g(X_M)}}), \]
    \[ \textcolor{blue}{f_M}(X)=\frac{1}{2}(1-x_1)(1+\boldsymbol{\textcolor{darkred}{g(X_M)}}) \]
