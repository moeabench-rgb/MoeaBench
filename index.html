    Framework

    MoeaBench is a framework for multi-objective optimization. The main idea is to provide a flexible tool that allows the user to test the ability of evolutionary algorithms to find redundancy of objectives in benchmark problems. It provides metrics, graphs, and other tools for data analysis.

    Benchmark problems

    Deb 2005: DTLZ1, DTLZ2, DTLZ3, DTLZ4, DTLZ5, DTLZ6, DTLZ7, DTLZ8

    XinYao-2022: DPF1, DPF2, DPF3, DPF4

    Algorithms

    Many-objective: NSGA-III, U-NSGA-III, SPEA-II, RVEA, MOEAD, configuration, arguments
