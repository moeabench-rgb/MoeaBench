# **Loader**

## **Instancia**
analyse = ANALYSE([engine](../main/engine.md))

## **Método**
<p style="font-size: 17px;">O método <strong>analyse.LOADER().CHOICE()</strong> carrega um arquivo com nomenclatura padrão do  <strong><i>Evobench</i></strong> com extensão .XLSX para ser utilizado pelas ferramentas de Análise.</p>

## [Arquivos](files.md)
<p style="font-size: 17px;">Configuração da nomenclatura de arquivos adotado no <strong><i>Evobench</i></strong>.</p>

### **Exemplo**
<p style="font-size: 17px;"><strong><i>R10_B15G300P100M3K5D2N6t083645.xlsx</i></strong>.</p>


### **Exception**      
<p style="font-size: 17px;">A ordem das siglas e os seus valores precisam ser obedecidos para gerar arquivo .XLSX</p>        


### **Notes** 
<p style="font-size: 17px;">Em LOADER(), apenas os arquivos .XLSX com padrão de nomenclatura exigida serão exibidos.</p>
